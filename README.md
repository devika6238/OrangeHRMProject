# OrangeHRM Test Automation Framework

This repository contains a modular Selenium test automation framework designed for validating the OrangeHRM web application.

---

## 🚀 CI/CD Pipeline Integration

This test automation framework is fully integrated with **Jenkins** for continuous local test execution.

### Automation Dashboard
![Jenkins Build Success](jenkins%20success.png)

### Framework Highlights:
* **Branch Tracking:** Automatically pulls and verifies updates from the `main` branch.
* **Build Execution:** Cleans and runs the Selenium suite utilizing top-level Maven targets (`clean test`).
* **Execution Metrics:** Tracks chronological build logs, ensuring a 100% test pass rate across runs.
